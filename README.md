A **responsive and customizable portfolio template** for creatives to showcase their projects. This template is designed to be visually appealing, interactive, and adaptable for different creators.

---

## 📌 Features

- Fully **responsive design** (mobile-first approach)
- **Semantic HTML5** structure
- **CSS3** styling with clean layouts
- **JavaScript interactions** for dynamic elements
- **Accessibility-ready** (ARIA landmarks, focus styles, alt text)
- Favicon and meta setup for a professional touch
- Ready for **customization** by different users

---

## 🎯 Learning Objectives

This project focuses on:

- Semantic HTML  
- Mobile-first & responsive design  
- Web accessibility (WCAG 2.1 AA awareness)  
- CSS Flexbox & Grid  
- Basic JavaScript interactions  
- Interactive UI elements  
- Color theory and typography  
- Cross-browser compatibility

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Animations:** GSAP, CSS transitions
- **Fonts:** Google Fonts (Poppins, Noto Serif)
- **Deployment:** GitHub Pages / Vercel / Netlify (choose your platform)
- **Optional Libraries:** ScrollTrigger, Intersection Observer for animations

## Customization Guide

- Colors and Fonts: Modify the CSS variables in :root for colors, typography, and theme.

- Projects: Update the .projects-grid with your images, titles, and tags.

- About Section: Replace text and abilities with your personal information.

- Contact Section: Update email, social links, and contact form behavior.

- Animations: Modify GSAP or CSS transitions in main.js or style.css for custom effects.

## AI Agent Usage Policy

This project involved the use of AI assistants to help with planning, code suggestions, and workflow optimizations. All AI interactions strictly followed a **two-phase workflow** to ensure transparency and maintain personal authorship:

### Phase 1: Planning
Before writing any code or implementing features, I consulted an AI assistant to **develop a detailed plan** for the feature or section of the project.  
Example of planning:
- Discussed layout and structure of the projects grid.
- Planned animations for hero text and particles.
- Defined responsive behavior and dark mode toggling logic.

### Phase 2: Implementation
After documenting the plan, I **implemented the code myself** based on the AI-assisted plan.  
- All final code was written and reviewed personally.
- AI suggestions were treated as guidance and **not blindly copied**.
- Citations for AI assistance are included where relevant.

**Important Notes:**
- AI was used strictly for planning, syntax suggestions, and conceptual guidance.
