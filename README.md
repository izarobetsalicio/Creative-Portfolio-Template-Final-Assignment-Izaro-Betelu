# Creative-Portfolio-Template-Final-Assignment-Izaro-Betelu

A **responsive and customizable portfolio template** for creatives to showcase their projects. This template is designed to be visually appealing, interactive, and adaptable for different creators.

---

## 📌 Features

- Fully **responsive design** (mobile-first approach)
- **Semantic HTML5** structure
- **CSS3** styling with clean layouts
- **JavaScript interactions** for dynamic elements
- **Accessibility-ready** (ARIA landmarks, focus styles, alt text)
- Favicon and meta setup for a professional touch
- Ready for **customization** by different users

---

## 🎯 Learning Objectives

This project focuses on:

- Semantic HTML  
- Mobile-first & responsive design  
- Web accessibility (WCAG 2.1 AA awareness)  
- CSS Flexbox & Grid  
- Basic JavaScript interactions  
- Interactive UI elements  
- Color theory and typography  
- Cross-browser compatibility
